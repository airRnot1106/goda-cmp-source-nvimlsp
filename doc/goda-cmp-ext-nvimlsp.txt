INTRODUCTION                              *goda-cmp-ext-nvimlsp-introduction*

                                                       *goda-cmp-ext-nvimlsp*
A goda-cmp.vim source that asks the LSP clients Neovim already has attached to
the buffer.  It starts no language server.  The source is named "nvimlsp".

==============================================================================
INSTALL                                        *goda-cmp-ext-nvimlsp-install*

It needs goda-cmp.vim, goda.vim and Neovim nightly (0.13).

https://github.com/Shougo/goda-cmp.vim
https://github.com/Shougo/goda.vim

Add the Go package to your configuration module.  Its Lua module is embedded
in the binary, so no plugin needs to be installed: >

	go get github.com/airRnot1106/goda-cmp-ext-nvimlsp.vim
<
==============================================================================
EXAMPLES                                      *goda-cmp-ext-nvimlsp-examples*
>go
	import "github.com/airRnot1106/goda-cmp-ext-nvimlsp.vim/ext/source/nvimlsp"

	b.AddSource(nvimlsp.New(nvimlsp.Params{
		EnableResolveItem:        true,
		EnableAdditionalTextEdit: true,
	}))
<
Add "nvimlsp" to `Sources` and call |goda_cmp#build()|.  For the preview of
the selected item, set pum.vim's previewer option to
"goda_cmp#get_previewer" (|goda-cmp-preview|).

==============================================================================
PARAMS                                          *goda-cmp-ext-nvimlsp-params*

The parameters are also accepted in sourceParams with these JSON names.

enableResolveItem		Sends completionItem/resolve for the selected
				and the accepted item.
enableAdditionalTextEdit	Applies additionalTextEdits (an auto import)
				when an item is accepted.
